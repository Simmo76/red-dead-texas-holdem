# Settings UI integration
Use panel.png as decorative background and title.png as reference (panel already has a blank title plaque; overlay live SETTINGS text instead of stacking two plaques). Use selector-blank.png for all five selectors, with live values and accessible names. Field textures are blank; use a real editable input. Button images are visual skins, not interaction surfaces: use semantic buttons with accessible names and live text where feasible. Maintain at least 44 x 44 pt hit areas, adequate spacing, safe areas, scrollable content in landscape, text scaling, VoiceOver focus, contrast (aim 4.5:1 for normal text), visible focus/pressed/disabled states, and confirmation before restart. Do not rely on color alone. Preserve existing settings behavior and persistence. Use CSS border-image or nine-slice where appropriate; avoid stretching corners. Test on small iPhones, with VoiceOver and larger text. Assets are decorative crops with geometric alpha masks; inspect edges and selector texture before shipping. No claim of Apple approval.
